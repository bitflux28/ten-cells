# Ten Cells 0.21.0

- Longer climb to the endgame: every prestige layer pays half as much (Fragments, Singularities, Ascension Cores, Void Essence, Infinity Points and Ultra Points). The first reset of each layer still pays at least 1
- Random events are rarer: one every 2.5 to 6 minutes (was 1 to 3), and event frequency boosts stack up to ×3 at most, so the late game no longer gets an event every few seconds

Also in 0.20.2: a new look for the atom on the Engine screen (cyan, pink and gold orbit rings, electrons with tails, a soft light behind the core, a dark outline).
